# Conexão AgroVerde 🌾🛒

**Plataforma Web Dinâmica para Vitrine Digital e Gestão da Agricultura Familiar**  
**Projeto Integrador / UFMS Digital 
*Desenvolvimento Web com Frameworks e HTML/CSS*

---

## 📖 Visão Geral do Projeto
O **Conexão AgroVerde** é uma aplicação web voltada a aproximar os pequenos produtores rurais e cooperativas da agricultura familiar da comunidade consumidora e do comércio local em Mato Grosso do Sul. A plataforma soluciona gargalos históricos de intermediação abusiva e perdas de safra, permitindo o cadastro ágil de alimentos agroecológicos e a formação de cestas com checkout direto para o WhatsApp dos cooperados.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5 Semântico:** Estruturação orientada a padrões de acessibilidade (`header`, `main`, `section`, `article`, `footer`, tags de formulário acessíveis).
- **CSS3 Moderno / Tailwind CSS (via CDN):** Design responsivo mobile-first, paleta temática agroecológica (Emerald, Amber, Slate) e componentes utilitários de alta performance.
- **JavaScript (ES6+):** Renderização reativa do catálogo, manipulação do DOM, persistência de dados local (`localStorage`), cálculo em tempo real de itens/valores e formatação dinâmica de pedidos.
- **Lucide Icons:** Biblioteca vetorial de ícones leves para reforço da usabilidade e comunicação visual intuitiva.

---

## ⚙️ Principais Funcionalidades Implementadas
1. **Vitrine Dinâmica de Produtos:** Exibição em cards responsivos com foto, unidade de venda, identificação do produtor rural e valor unitário.
2. **Filtro de Categorias em Tempo Real:** Filtragem dinâmica sem recarregamento de página (*Hortaliças, Frutas, Tubérculos e Derivados*).
3. **Painel de Cadastro de Produtos (Visão Produtor):** Modal interativo que permite ao cooperado cadastrar novos itens, precificação e lote com persistência local instantânea.
4. **Cesta de Compras e Resumo de Pedido:** Gaveta interativa (Drawer) com incremento/decremento de unidades, cálculo de subtotal e total geral.
5. **Checkout Solidário via WhatsApp:** Geração automática de link codificado (`wa.me`) que transfere os dados formatados do pedido para o produtor responsável.

## 🚀 Como Executar o Projeto Localmente
Não é necessária nenhuma instalação complexa de compiladores ou servidores backend:
1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/gustavoribeiro-coder
/conexao-agroverde.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd conexao-agroverde
   ```
3. Abra o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) com um duplo clique.
